Civilization V (Steam, macOS) — сетевая игра с Windows-игроками
================================================================

Проблема
--------
Mac-версия (64-битный порт Aspyr) при подключении сообщает номер билда
180925, Windows-версия — 403694. Игра сравнивает номера и пишет
«Несовпадение версии с игроком», хотя правила и файлы игры одинаковые.

Решение
-------
crossplay.sh меняет номер билда в двух файлах внутри приложения:
  Civilization V.app/Contents/Info.plist                      (CFBundleVersion)
  Civilization V.app/Contents/AspyrAssets/global/String/App.json (App.Build)
на 403694 и затем переподписывает приложение локальной подписью (codesign
ad-hoc), иначе macOS убивает лаунчер при запуске. Оригиналы сохраняются в
  ~/Library/Application Support/Sid Meier's Civilization 5/crossplay-backup/

Проверено в живой партии: 3 игрока (2 Windows + Mac), 160 ходов, 1 ч 47 мин.
Один рассинхрон на 1–2 ходу, который игра сама починила пересинхронизацией,
дальше три разовых расхождения счётчиков, исчезнувшие на следующем ходу.

Установка на любом Маке
-----------------------
1. Скопируй папку Civ5-crossplay на Мак (например, в Загрузки).
2. Закрой игру (Steam может быть запущен).
3. В Терминале:
     cd ~/Downloads/Civ5-Mac/Civ5-crossplay
     chmod +x crossplay.sh
     ./crossplay.sh install
4. Запускай игру из Steam как обычно и подключайся к лобби.

Команды
-------
  ./crossplay.sh status    — показать, применён ли патч и валидна ли подпись
  ./crossplay.sh install   — применить (и переподписать)
  ./crossplay.sh restore   — вернуть оригинальный билд
  ./crossplay.sh sign      — только переподписать (после install.sh и других правок)

Если библиотека Steam лежит не в стандартном месте:
  CIV5_APP="/Volumes/Диск/SteamLibrary/steamapps/common/Sid Meier's Civilization V/Civilization V.app" ./crossplay.sh install

Важно
-----
- Обновление игры в Steam или «Свойства → Установленные файлы → Проверить
  целостность» возвращает оригинальные файлы. После этого снова: install.
  Перед игрой удобно запускать status.
- Windows-игрокам делать ничего не нужно.
- Все игроки должны иметь одинаковые дополнения и DLC включёнными в лобби
  (Gods & Kings, Brave New World, наборы цивилизаций) — это проверяется отдельно
  от номера версии.
- Если в игре появился значок рассинхронизации — хост в меню нажимает
  «Пересинхронизировать» (Resync), партия продолжается. Сохраняйтесь почаще,
  автосохранения лежат в ~/Library/Application Support/Sid Meier's Civilization 5/Saves/multi/auto/
- Если Steam пишет «Не удалось запустить процесс для игры: OS Error 256»,
  а macOS — «The application Civilization V can't be opened», это сломанная
  подпись (в отчёте о сбое: SIGKILL Code Signature Invalid). Лечится командой
  ./crossplay.sh sign. Может проявиться не сразу после правки, а через
  несколько дней: ядро кэширует результат старой проверки.
- codesign входит в саму macOS (/usr/bin/codesign), Xcode ставить не нужно.
- Это только патч версии. Русификация и другие правки сюда не входят.
