Civilization V (Steam, macOS) — текстуры карты TTE 2k
=====================================================

Terrain Texture Enhancement 2k v12 (автор Estebanium, CivFanatics):
https://forums.civfanatics.com/threads/terrain-texture-enhancement-2k.570307/
73 текстуры DDS: местность четырёх стилей (Европа/Азия/Африка/Америка) 2048×2048 вместо
1024, горы, болота, тундра, снег, реки, основания городов, часть чудес природы.
Кода нет — только DDS и описание DLC (TTE_2k.Civ5Pkg).

Сам мод в публичной версии пакета не лежит (это работа автора): скачай архив по ссылке
выше (Mega, ~136 МБ, .7z), распакуй и положи папку TTE_2k в Civ5-terrain/payload/.

Ставится как DLC-папка Contents/Assets/Assets/DLC/TTE_2k, оригинальные файлы игры
не трогаются. 71 из 73 текстур совпадают по именам с Resource/DX9/TerrainTextures.fpk
Mac-сборки (формат DXT5/ARGB с mip-уровнями, как у оригинала).

Без Терминала: «3. Текстуры карты вкл-выкл.command» в корне Civ5-Mac.

Команды (игра закрыта):
  ./terrain.sh install     поставить (сам переподписывает игру через crossplay.sh sign)
  ./terrain.sh uninstall   убрать
  ./terrain.sh status
  ./terrain.sh fixcache    если игра закрывается на загрузке (пустой Localization-Merged.db)

Порядок со всем пакетом: install.sh → options.sh → tweaks.sh → terrain.sh install →
crossplay.sh install (последним). После обновления игры или «Проверки целостности»
в Steam — тот же порядок (см. Civ5-ru-patch/README.txt).

Кэш: скрипт удаляет только cache/Localization-*.db. Весь cache/*.db удалять нельзя —
на Mac после этого игра собирает пустой Localization-Merged.db и закрывается на загрузке
(так случилось 2026-11-13 с первой версией скрипта). Если это произошло: ./terrain.sh fixcache

Заметки
- Чисто графический мод, правила не меняет. Автор пишет, что работает в сетевой игре;
  с Mac ↔ Windows не проверено. Если лобби ругается на DLC — uninstall перед партией.
- Видеопамяти нужно больше; на M4 Pro не критично. В настройках игры
  «Сжатие текстур» лучше выключить — так текстуры чётче (совет автора).
- На форуме жаловались на слишком контрастный рельеф и заметные повторы. Не нравится — uninstall.
